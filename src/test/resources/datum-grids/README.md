# NZGD49 to NZGD2000 test grid

`nzgd2kgrid0005.gsb` is the NTv2 distortion grid produced by Land Information New Zealand (LINZ) for converting
coordinates from NZGD49 to NZGD2000. The test fixture is an unmodified copy from the historic
[OSGeo PROJ datum-grid repository](https://github.com/OSGeo/proj-datumgrid/blob/master/nzgd2kgrid0005.gsb), with
SHA-256 checksum `116d54c9ad2f7082610d887439106bac23d2df364b48506acf6c82ca8b5aba1d`.
